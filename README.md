# OrangeBot
A Slack bot made with a passion for oranges. It was created for stardance mission project.

***

## Commands

| Command      | Description                                                   |
| ------------ | ------------------------------------------------------------- |
| `/orangebot-ping`      | Replies with `Pong!`.                               |
| `/orangebot-help`      | Shows possible commands.                            |
| `/orangebot-joke`      | Tells a joke.                                       |
| `/orangebot-catfact`   | Gives a cat fact.                                   |

***

### How to use
1. Head over to the dedicated channel for this bot: https://hackclub.enterprise.slack.com/archives/C0BUAURDA6L
2. Send one of the command messages from above.

***
